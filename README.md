# 📝 Full-Stack To-Do List Web Application

This repository contains the full-stack To-Do List project, with a **Node.js backend** and **React frontend**. It allows users to manage notes and tasks securely with JWT authentication and personal vaults.

---

## 🔧 Tech Stack

- **Backend:** Node.js, Express.js, MongoDB, JWT, bcrypt  
- **Frontend:** React.js, Tailwind CSS, Axios  
- **Database:** MongoDB  
- **Version Control:** Git & GitHub  

---

## 🚀 Features

- Full user authentication and authorization with JWT  
- CRUD operations for notes with advanced features: categories, search, filter, sort, and pagination  
- Personal secure vault for private notes with secondary password and activity logging  
- Responsive and user-friendly interface built with React and Tailwind CSS  
- Complete integration between frontend and backend using REST APIs
